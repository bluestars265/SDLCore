# SDLCore 学习教程

欢迎！本教程带你**从零开始**熟悉 **SDLCore** —— 基于 PySDL2 的通用 GUI 引擎 + MOD 化游戏框架。
学习完成后，你将能独立使用 SDLCore 组装界面、管理场景、编写自己的 MOD 与游戏逻辑。

## 前置知识

- Python 3.13 基础语法（变量、函数、类、列表/字典）
- 基本的面向对象概念（类、继承、方法）

## 阅读建议

- 每章均含**可直接运行**的代码，建议边读边动手。
- 需要查询 API 细节时，参考 `doc/` 下的参考文档（`widget.md`、`panel.md`、`layout.md` 等）。
- 结合项目源码阅读效果更佳：`SDLCore/` 是引擎层，`mods/base_game/` 是游戏主体。
- 学完所有章节后，尝试在 `mods/base_game/` 中新增自己的场景。

## 项目结构速览

```
II/
├── main.py                 # 启动入口：仅加载主 mod 与其他 mod 并驱动主循环
├── test_main.py            # 测试启动入口（额外加载 test_mods/）
├── SDLCore/                # 通用引擎层（GUI 控件、布局、场景、资源、MOD 系统）
│   └── ui/                 #   控件库（widget/panel/button/...）
├── mods/
│   ├── base_game/          # 主游戏 mod（游戏主体：loading/start 场景）
│   └── demo_mod/           # 第三方演示 mod
├── test_mods/test_game/    # 控件测试 mod（仅测试启动时加载）
├── resource/               # 根资源（字体等）
├── doc/                    # SDLCore 参考文档（本目录为教程）
└── game_doc/               # 游戏逻辑层文档
```
