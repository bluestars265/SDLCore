03 布局系统

目标：不再手工计算每个控件的坐标，而是用布局对象自动排布子控件。

1. 为什么需要布局？

手写坐标在窗口尺寸变化时会很快失控。SDLCore 的 Layout 机制让容器自动计算子控件位置。

from SDLCore.ui.panel import Panel
from SDLCore.ui.layout import VBoxLayout, HBoxLayout, GridLayout

2. VBoxLayout：垂直堆叠

panel = Panel((100, 80, 400, 320), color=(30, 30, 40, 230),
              layout=VBoxLayout(spacing=10, padding=(20, 20, 20, 20)))
panel.add_child(Button((0, 0, -1, 48), text="按钮 1"))   # w=-1 → 填满可用宽度
panel.add_child(Button((0, 0, -1, 48), text="按钮 2"))
panel.add_child(Button((0, 0, -1, 48), text="按钮 3"))

效果：三个按钮自上而下等距排列，宽度自动占满（减 padding）。

w == -1 表示填满可用宽度，是布局中最重要的自适应约定之一。

3. HBoxLayout：水平排列

bar = Panel((100, 80, 400, 60), layout=HBoxLayout(spacing=8))
bar.add_child(Button((0, 0, 100, -1), text="左"))    # h=-1 → 填满高度
bar.add_child(Button((0, 0, 100, -1), text="中"))
bar.add_child(Button((0, 0, 100, -1), text="右"))

4. GridLayout：网格排布

grid = Panel((100, 80, 420, 260), color=(30, 30, 40, 230),
             layout=GridLayout(cols=3, h_spacing=10, v_spacing=10,
                               padding=(16, 16, 16, 16)))
for i in range(6):
    grid.add_child(Button((0, 0, -1, -1), text=f"格子 {i}"))

效果：3 列 × 2 行，行数自动计算。子控件 w/h = -1 填满单元格。

5. 参数说明

布局参数默认说明
VBoxLayoutspacing5子项垂直间距
padding(0,0,0,0)内边距 (左,上,右,下)
align"stretch"子项对齐方式
HBoxLayout同上—水平版本
GridLayoutcols1列数
cell_width/height0固定单元格尺寸（0=自动均分）
h_spacing/v_spacing5单元格间距
padding(5,5,5,5)内边距

6. 自适应尺寸（fit_content 与 Constraints）

Widget.measure(constraints) 返回控件的首选尺寸，供布局按内容自适应：

from SDLCore.ui.layout import Constraints

label = Label((0, 0, 0, 24), text="一段文字")
w, h = label.measure()          # 按文字内容测量，如 (96, 24)
  • Constraints(min_w, max_w, min_h, max_h) 约束测量范围。
  • fit_content=True 的 Button 会按文字宽度自动撑开。

7. 何时重新布局？

布局是即时生效的：add_child / remove_child / 容器 set_rect（含窗口 resize）时， Panel 会自动调用布局对象重排子控件。

panel.set_rect((50, 50, 500, 400))   # 子控件立即按新尺寸重排
