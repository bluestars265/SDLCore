02 核心概念与控件体系

目标：理解 SDLCore 最基本的抽象 —— Widget（控件），以及控件如何组成一棵树。

1. 一切皆 Widget

所有可见可交互的东西（按钮、文字、面板、输入框…）都是 Widget 的子类。 Widget 基类（SDLCore/ui/widget.py）定义了三组通用能力：

能力说明
坐标rect（相对父容器）/ abs_rect（世界绝对坐标）
状态visible（可见性）、enabled（可用性）、layer（图层）、opacity（透明度）
生命周期handle_event()、update(dt)、render(renderer)

坐标系统

# rect = (x, y, w, h)，x/y 是【相对父容器】的偏移
btn = Button((50, 30, 160, 48), text="确定")

# 常用坐标方法
btn.set_position(20, 10)      # 仅改位置
btn.set_size(200, 56)         # 仅改尺寸
btn.set_rect((0, 0, 200, 56)) # 同时改位置与尺寸
  • rect 是相对坐标；渲染与事件检测使用 abs_rect（由 update_abs_position() 递归计算）。
  • 放入容器后，abs_rect = 容器绝对坐标 + 自身 rect。

状态控制

btn.set_visible(True)     # 显示/隐藏（隐藏后不渲染、不接收事件）
btn.set_enabled(False)    # 禁用（仍显示，但不接收事件）
btn.set_opacity(0.5)      # 透明度 0.0~1.0（父容器会向下传播透明度）

2. 控件树

Panel 是容器控件：可以挂载任意子控件，组成树状结构。

from SDLCore.ui.panel import Panel
from SDLCore.ui.button import Button

panel = Panel((0, 0, 400, 300), color=(30, 30, 40, 220))
btn = Button((20, 20, 160, 48), text="按钮 A")
panel.add_child(btn)          # 挂载子控件
  • 渲染：容器先画自身背景，再按 layer 从低到高 画子控件。
  • 事件：按 layer 从高到低 分发，某控件消费（返回 True）即停止。
  • 添加/移除：add_child(widget) / remove_child(widget)。
panel.remove_child(btn)   # 解除父子关系

3. 图层（layer）

layer 决定重叠控件的绘制顺序与事件优先级：

low  = Panel((10, 10, 200, 200))   # layer 默认 0
high = Panel((50, 50, 200, 200))   # layer 默认 0
high.layer = 10                     # 提到上层
  • 绘制：layer 大的后绘制（显示在上层）。
  • 事件：layer 大的先收到事件。

4. 生命周期钩子

每个控件每帧会被依次调用：

主循环
  → ui.resize(w, h)            # 根面板铺满全屏，刷新绝对坐标
  → ui.handle_events(events)   # 事件分发
  → ui.update(delta_time)      # 每帧逻辑更新
  → ui.render(renderer)        # 渲染整棵控件树
class MyWidget(Widget):
    def __init__(self, rect):
        super().__init__(rect)

    def update(self, delta_time):     # 每帧更新（dt 单位：秒）
        super().update(delta_time)

    def render(self, renderer):       # 绘制
        if not self.visible:
            return
        renderer.fill(self.abs_rect, (255, 120, 0, 255))

5. 把它们组合起来：第一个 UI 程序

import sdl2
import sdl2.ext
from SDLCore.ui.manager import UIManager
from SDLCore.ui.panel import Panel
from SDLCore.ui.button import Button
from SDLCore.ui.label import Label

def main():
    sdl2.ext.init()
    window = sdl2.ext.Window(
        "第一个 UI", size=(800, 600),
        flags=sdl2.SDL_WINDOW_RESIZABLE | sdl2.SDL_WINDOW_SHOWN,
    )
    renderer = sdl2.ext.Renderer(window, flags=sdl2.SDL_RENDERER_ACCELERATED)
    factory = sdl2.ext.SpriteFactory(sdl2.ext.TEXTURE, renderer=renderer)

    ui = UIManager()                     # UI 总控：持有根面板、负责事件/渲染
    panel = Panel((100, 100, 400, 300), color=(30, 30, 40, 230))
    btn = Button((60, 60, 160, 48), text="点击我",
                 callback=lambda: print("按钮被点击！"))
    title = Label((60, 20, 0, 24), text="我的第一个界面", factory=factory)
    panel.add_child(title)
    panel.add_child(btn)
    ui.root_panel.add_child(panel)

    running = True
    while running:
        events = sdl2.ext.get_events()
        for e in events:
            if e.type == sdl2.SDL_QUIT:
                running = False
        w, h = window.size               # 每帧实时获取窗口尺寸
        ui.resize(w, h)
        ui.handle_events(events)
        ui.update(1 / 60)
        renderer.clear((40, 44, 56))
        ui.render(renderer)
        renderer.present()
        sdl2.SDL_Delay(16)

    window.close()
    sdl2.SDL_Quit()

if __name__ == "__main__":
    main()

运行后：窗口中出现一个带标题和按钮的面板，点击按钮会在终端输出"按钮被点击！"。

Label 与 Button 需要 factory 才能渲染文字 —— 它就是 SpriteFactory(sdl2.ext.TEXTURE, renderer=...)。
