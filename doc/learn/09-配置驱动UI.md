# 09 配置驱动 UI

目标：用 JSON 声明界面结构，用 Python 注入行为 —— **"结构用配置，行为用代码"**。

## 1. 一个 JSON 场景

```json
{
  "type": "panel",
  "id": "root",
  "rect": [100, 80, 400, 300],
  "color": [30, 30, 40, 230],
  "layout": {"type": "vbox", "spacing": 12, "padding": [20, 20, 20, 20]},
  "children": [
    {"type": "label", "id": "title", "rect": [0, 0, -1, 30],
     "text": "设置面板", "color": [0, 200, 200, 255]},
    {"type": "button", "id": "ok_btn", "rect": [0, 0, -1, 48],
     "text": "确定", "on_click": "on_ok"},
    {"type": "slider", "id": "vol", "rect": [0, 0, -1, 30],
     "min": 0, "max": 100, "value": 50, "on_value_changed": "on_volume"}
  ]
}
```

## 2. 用 UIBuilder 构建

```python
from SDLCore.ui.builder import UIBuilder

builder = UIBuilder(factory=factory)
root = builder.build_file("scenes/settings/scene.json", bindings={
    "on_ok": lambda: print("确定"),
    "on_volume": lambda v: print("音量:", v),
})
ui.root_panel.add_child(root)
```

- `bindings`：JSON 中 `"on_click": "on_ok"` 里的处理器名 → 代码回调。
- 构建后按 `id` 访问：`builder.by_id["ok_btn"].set_enabled(False)`。

## 3. 通用属性

对所有控件类型统一生效：

| 属性 | 说明 |
|---|---|
| `"id"` | 控件标识（登记到 `builder.by_id`） |
| `"layer"` | 图层（越大越靠上） |
| `"weight"` | 布局权重（flex） |
| `"opacity"` | 透明度 0.0~1.0 |
| `"rect"` | `[x, y, w, h]`；`w=-1` 填满宽度、`h=-1` 填满高度 |

## 4. 内置控件类型

`panel` / `button` / `image_button` / `label` / `inputbox` / `checkbox` /
`radio_group` / `slider` / `listbox` / `combobox` / `progress_bar` / `scroll_panel`
（`layout` 支持 `vbox` / `hbox` / `grid`）。

```json
{"type": "image_button", "image_normal": "images/btn.png",
 "image_hover": "images/btn_h.png", "text": "开始"}
```

## 5. 组件复用：$ref

把重复组件抽成独立 JSON，用 `$ref` 引用 + `override` 覆盖：

```json
{"$ref": "components/ok_button.json"}
{"$ref": "components/ok_button.json",
 "override": {"id": "cancel_btn", "text": "取消"}}
```

## 6. 自定义控件类型

通过 `ComponentRegistry` 注册工厂，JSON 中即可使用任意类型：

```python
from SDLCore.ui.builder import ComponentRegistry, UIBuilder

registry = ComponentRegistry()
registry.register("blink", lambda props, ctx: BlinkSquare(tuple(props["rect"])))
builder = UIBuilder(factory=factory, registry=registry)
# JSON: {"type": "blink", "rect": [80, 0, 120, 60]}
```

## 7. 与 MOD 系统配合

`ModScene` 自动用 `UIBuilder` 加载 mod 场景 JSON：

```python
api.add_scene("menu", "主菜单", "scenes/menu/scene.json",
              bindings={"on_start": start_game})
```

- 资源相对路径经 `resource_resolver` 映射到 mod 目录（支持 `@mod_id/` 跨 mod 引用）。
- 共享 registry：各 mod 注册的自定义控件所有场景可用。
