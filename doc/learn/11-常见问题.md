# 11 常见问题（FAQ）

收集开发中常遇到的问题与排查思路。

## Q1. 文字显示不出来？

**原因**：`Label` / `Button`（文字）/ `InputBox` 需要 `factory`（`SpriteFactory(TEXTURE)`）才能渲染文字。

**解决**：

```python
factory = sdl2.ext.SpriteFactory(sdl2.ext.TEXTURE, renderer=renderer)
Label((0, 0, 0, 24), text="文字", factory=factory)   # 构造时传入
# 或稍后 set_factory(factory)
```

**另外**：字体从 `resource/fonts/` 或系统字体查找（中文用 SimHei 等）；找不到会报错。

## Q2. 图片/纹理被拉伸到整个屏幕？

**原因**：`renderer.copy(sprite, dstrect=...)` **必须显式传 dstrect**；缺省会把纹理拉伸到整个渲染目标。

**解决**：总是传 `dstrect=(x, y, w, h)`。

```python
renderer.copy(sprite, dstrect=(100, 100, 200, 50))
```

## Q3. 窗口缩放后控件位置不对？

**原因**：忘记每帧用实时窗口尺寸刷新 UI。

**解决**：主循环中每帧调用 `ui.resize(w, h)`（或 `scene_manager.resize(w, h)`）：

```python
w, h = window.size
ui.resize(w, h)          # 根面板铺满 + 递归刷新绝对坐标 + 触发 on_resize
```

## Q4. 输入中文没反应 / 没有候选词？

**检查点**：

- 必须在**创建窗口之前**设置 IME hint：

```python
sdl2.SDL_SetHint(b"SDL_IME_SHOW_UI", b"1")   # 在 Window() 之前
```

- `InputBox` 需要 `factory`。
- 点击输入框激活后 `SDL_StartTextInput()` 才生效。

## Q5. 点击按钮没反应？

**检查点**：

- 控件是否 `visible` 且 `enabled`？
- 是否被上层 `layer` 更大的控件"盖住"（事件被消费）？
- `abs_rect` 是否正确（是否调用了 `update_abs_position` / 每帧 `resize`）？
- 回调是否在**按下并释放**时触发（`Button` 行为）？

## Q6. 运行时提示 "未设置渲染工厂" / "IMG_Load 失败"？

- `resources.set_factory(factory)` 是否已调用（应用启动时一次）？
- 图片路径是否存在？SVG 是否用了 SDL_image 2.8+（pysdl2-dll 2.32.10 已内置）？

## Q7. 帧率被卡 / 循环太快？

- **禁止 `time.sleep()`**。主循环用 `sdl2.SDL_Delay(16)` 锁帧。
- Delta Time 用 `sdl2.SDL_GetTicks()` 计算：

```python
now = sdl2.SDL_GetTicks()
dt = (now - prev) / 1000.0
prev = now
```

## Q8. 半透明颜色显示为纯色？

半透明绘制需要 alpha 混合。SDLCore 控件已自动处理
（`enable_alpha_blend` + `BatchedRenderer` 自动把半透明矩形移出合批）。
若自绘代码，需先开启混合：`sdl2.SDL_SetRenderDrawBlendMode(renderer, sdl2.SDL_BLENDMODE_BLEND)`。

## Q9. 控件性能如何优化？

- 不透明矩形会**合批**（`BatchedRenderer`）：同色一次 `SDL_RenderFillRects`。
- 尽量少用半透明矩形（会破坏合批）。
- 纹理经 `ResourceManager` 缓存，同一路径只加载一次。
- 异步加载大图：`load_async` + 每帧 `process_pending`。

## Q10. 我想新增一个游戏场景，该怎么做？

按约定，场景写在**主 mod（`mods/base_game/`）**：

1. 在 `mods/base_game/` 新建 `my_scene.py`，定义 `class MyScene(Scene)`。
2. 在 `mods/base_game/main.py` 的 `register(api)` 中：

```python
scene_mod = _load_mod_module(api, "my_scene.py")
api.register_scene("my_scene", scene_mod.MyScene)
```

3. 运行时 `manager.switch("my_scene")` 切换进入。
