# 01 环境准备与第一个窗口

目标：安装 SDLCore 运行环境，并写出你的**第一个 SDL2 窗口程序**。

## 1. 环境要求

| 项目 | 要求 |
|---|---|
| Python | 3.13 及以上（支持新式类型注解 `list[str]` / `A \| None`） |
| 图形库 | **PySDL2**（`sdl2`、`sdl2.ext`）+ 运行时 DLL（`pysdl2-dll`） |
| 系统 | Windows（本项目当前开发环境） |

## 2. 安装

```bash
pip install pysdl2 pysdl2-dll
```

> **重要**：`pysdl2-dll` 已内置 SDL2 全系列 DLL（含 **SDL_image 2.8+**，原生支持 SVG）。
> 无需手动设置 `PYSDL2_DLL_PATH`，直接 `import sdl2` 即可。

## 3. 最小窗口程序

创建 `hello.py`（可放在项目根目录临时使用）：

```python
# hello.py —— 最小 SDL2 窗口
import sdl2
import sdl2.ext

WIDTH, HEIGHT = 800, 600

def main():
    # 1) 初始化 SDL2
    sdl2.ext.init()

    # 2) 创建窗口（允许拖拽缩放）
    window = sdl2.ext.Window(
        "Hello SDLCore",
        size=(WIDTH, HEIGHT),
        flags=sdl2.SDL_WINDOW_RESIZABLE | sdl2.SDL_WINDOW_SHOWN,
    )
    # 3) 创建硬件加速渲染器
    renderer = sdl2.ext.Renderer(window, flags=sdl2.SDL_RENDERER_ACCELERATED)

    # 4) 主循环
    running = True
    while running:
        # 收集并处理事件
        for event in sdl2.ext.get_events():
            if event.type == sdl2.SDL_QUIT:      # 点击窗口关闭按钮
                running = False

        # 每帧：清屏 → 绘制 → 呈现
        renderer.clear((40, 44, 56))
        renderer.present()

        sdl2.SDL_Delay(16)   # 锁帧约 60 FPS（禁止用 time.sleep）

    # 5) 清理
    window.close()
    sdl2.SDL_Quit()

if __name__ == "__main__":
    main()
```

运行：

```bash
python hello.py
```

你应该看到一个深色窗口，标题为 "Hello SDLCore"，可自由拖拽缩放。

## 4. 逐段讲解

- **`sdl2.ext.init()`**：初始化 SDL2 全部子系统（视频、事件等）。
- **`sdl2.ext.Window(...)`**：创建窗口。`SDL_WINDOW_RESIZABLE` 必须包含，允许缩放。
- **`sdl2.ext.Renderer(window, flags=...)`**：硬件加速渲染器（GPU）。
- **主循环**：`get_events()` 取事件 → 清屏 → 绘制 → `present()` 呈现。
- **帧率**：`SDL_Delay(16)` 约等于 60 FPS。**禁止使用 `time.sleep()`**。

## 5. 为什么要用 SDLCore 而不用裸 SDL2？

裸 SDL2 只有"画点、画矩形、贴纹理"原语。SDLCore 在此基础上提供：

```
裸 SDL2                    SDLCore
─────────────────────────────────────────
手动管理矩形坐标      →    Widget（rect/abs_rect 自动计算）
手动处理绘制顺序      →    控件树 + layer 图层
每次重画全部内容      →    控件渲染 + 合批优化（BatchedRenderer）
手动加载图片          →    ResourceManager 缓存 + 异步加载
手动组织多个界面      →    Scene / SceneManager
```
