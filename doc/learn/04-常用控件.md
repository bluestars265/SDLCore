# 04 常用控件

目标：认识 SDLCore 内置的常用控件与关键用法。完整 API 见 `doc/` 对应参考文档。

> 多数控件需要 `factory`（`SpriteFactory(TEXTURE)`）才能渲染文字/图片。

## 1. Label —— 文字标签

```python
from SDLCore.ui.label import Label

Label((10, 10, 0, 24), text="普通文字", color=(255, 255, 255, 255),
      font_size="16px", factory=factory)
```

- 只读文字，不接收事件。`set_text()` 运行时更新。

## 2. Button —— 按钮

```python
from SDLCore.ui.button import Button

btn = Button((50, 50, 160, 48), text="确定",
             callback=lambda: print("确定被点击"))
btn.set_callback(new_callback)     # 运行时改回调
```

- 三态颜色：常态灰 / 悬停浅蓝 / 按下深蓝。
- 回调在**按钮内按下并释放**时触发。

## 3. ImageButton —— 图片按钮（三态图片）

```python
from SDLCore.ui.imagebutton import ImageButton

img_btn = ImageButton(
    (50, 50, 180, 56), text="开始游戏", text_color=(255, 255, 255, 255),
    image_normal="resource/images/Blue/Default/button_rectangle_flat.png",
    image_hover="resource/images/Blue/Default/button_rectangle_gradient.png",
    image_pressed="resource/images/Blue/Default/button_rectangle_depth_flat.png",
    callback=lambda: print("开始游戏"),
    factory=factory,
)
```

- 图片支持 **PNG / SVG** 等格式；某状态缺图时回退为 `Button` 颜色渲染。
- 文字可选（`text` 非空时居中叠加）。

## 4. InputBox —— 文本输入框（支持中文 IME）

```python
from SDLCore.ui.inputbox import InputBox

InputBox((50, 50, 300, 40), font_size="18px", factory=factory,
         on_submit=lambda t: print("提交:", t))
```

- 点击激活启用系统输入法，支持中文拼音候选、光标、选区、复制粘贴。
- 焦点由 `UIManager` 自动管理。

## 5. CheckBox / RadioGroup —— 复选 / 单选

```python
from SDLCore.ui.checkbox import CheckBox
from SDLCore.ui.radiogroup import RadioGroup

CheckBox((50, 50, 200, 30), text="启用特效", factory=factory,
         callback=lambda v: print("选中:", v))

RadioGroup((50, 100, 220, 120), options=["低", "中", "高"],
           selected_index=1, factory=factory,
           on_select=lambda text, idx: print(text, idx))
```

## 6. Slider —— 滑动条

```python
from SDLCore.ui.slider import Slider

Slider((50, 50, 300, 30), min_val=0, max_val=100, value=50, step=5,
       factory=factory, on_value_changed=lambda v: print("音量:", v))
```

- 支持点击轨道跳转、拖拽滑块、`step` 步长对齐、数值显示。

## 7. ListBox —— 列表（多选 + Ctrl/Shift）

```python
from SDLCore.ui.listbox import ListBox

ListBox((50, 50, 220, 160), items=["选项 A", "选项 B", "选项 C"],
        allow_multi_select=True, factory=factory,
        on_selection_changed=lambda texts: print("选中:", texts))
```

## 8. ComboBox —— 下拉选择框

```python
from SDLCore.ui.combobox import ComboBox

ComboBox((50, 50, 200, 30), items=["方案一", "方案二", "方案三"],
         selected_index=0, factory=factory,
         on_select=lambda text, idx: print(text, idx))
```

- 下拉列表以高 layer 浮层挂在根面板上，不受容器裁剪。

## 9. ProgressBar —— 进度条

```python
from SDLCore.ui.progressbar import ProgressBar

bar = ProgressBar((50, 50, 300, 26), value=55, factory=factory)
bar.set_value(80)      # 0~100
bar.set_progress(0.8)  # 或用 0.0~1.0
```

- 支持纯色填充、`fill_image` 纹理填充、`indicator_image` 前端标记。

## 10. Image —— 图片控件

```python
from SDLCore.ui.image import Image

Image((50, 50, 480, 280), path="resource/images/png/logo.png")
# 或直接传已加载纹理
Image((50, 50, 480, 280), texture=sprite)
```

- **保持宽高比缩放并居中，不填充背景**，适合 logo / 图标。

## 11. ScrollPanel —— 滚动面板

```python
from SDLCore.ui.scrollpanel import ScrollPanel
from SDLCore.ui.layout import VBoxLayout

sp = ScrollPanel((50, 50, 260, 200), content_size=(260, 600))  # 内容比视口高
sp.content.set_layout(VBoxLayout(spacing=6))
for i in range(20):
    sp.add_child(Label((8, 0, -1, 24), text=f"第 {i} 行", factory=factory))
```

- 滚轮滚动、滚动条拖拽、视口裁剪；`add_child` 挂到内部 `content`。

## 12. Panel —— 容器（透明/半透明背景）

```python
from SDLCore.ui.panel import Panel

Panel((100, 100, 400, 300), color=(30, 30, 40, 220))   # RGBA，A 控制透明度
Panel((100, 100, 400, 300), color=(0, 0, 0, 0))        # 完全透明
```

## 速查表

| 控件 | 典型用途 | 关键参数 |
|---|---|---|
| `Label` | 静态文字 | `text/color/font_size` |
| `Button` | 点击动作 | `text/callback` |
| `ImageButton` | 图片按钮 | `image_normal/hover/pressed/text` |
| `InputBox` | 文本输入 | `font_size/on_submit` |
| `CheckBox` | 布尔开关 | `checked/callback` |
| `RadioGroup` | 互斥选择 | `options/selected_index/on_select` |
| `Slider` | 数值调节 | `min_val/max_val/step` |
| `ListBox` | 列表选择 | `items/allow_multi_select` |
| `ComboBox` | 下拉选择 | `items/selected_index` |
| `ProgressBar` | 进度显示 | `value/fill_color/fill_image` |
| `Image` | 图片展示 | `path/texture` |
| `ScrollPanel` | 滚动区域 | `content_size/thumb_image` |
| `Panel` | 容器 | `color/layout` |
