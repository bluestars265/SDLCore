05 事件与交互

目标：理解事件如何分发到控件，以及如何编写自定义交互控件。

1. 事件分发机制

主循环把 SDL 事件交给 UIManager.handle_events(events)，它会：

  1. IME 文本事件（SDL_TEXTINPUT / SDL_TEXTEDITING）直接发送给焦点控件（如输入框）。
  2. 其余事件（鼠标、键盘）按 layer 从高到低 遍历根面板子控件，

某控件 handle_event 返回 True（消费）即停止传递。

def handle_event(self, event) -> bool:
    if not self.visible or not self.enabled:
        return False
    if event.type == sdl2.SDL_MOUSEBUTTONDOWN:
        if event.button.button == sdl2.SDL_BUTTON_LEFT and self._contains(event.button.x, event.button.y):
            print("点到了我")
            return True       # 消费：事件不再下传
    return False              # 不消费：继续分发给下层控件
  • event.button.x/y 是窗口坐标，用 self._contains(x, y) 判断是否落在控件内。

2. 悬停钩子

Widget 基类内置悬停跟踪：鼠标进入/离开控件时调用钩子，便于实现提示框等。

class TooltipButton(Button):
    def on_mouse_enter(self):
        print("鼠标进入！")   # 可在此显示提示框

    def on_mouse_leave(self):
        print("鼠标离开")
重写了 handle_event 的控件需在 MOUSEMOTION 分支调用 self._update_hover(x, y)<br>才能启用钩子（内置控件已默认接入）。

3. 焦点（Focus）

UIManager.set_focus(widget) 设置当前持有焦点的控件（如 InputBox）：

  • 键盘事件优先发送给焦点控件（回车、退格、方向键等）。
  • 点击输入框自动获得焦点；点击外部由控件自行失焦。
ui.set_focus(my_inputbox)    # 手动指定焦点
ui.set_focus(None)           # 清除焦点

4. 自定义控件

继承 Widget，实现 update / render / 可选 handle_event 即可。

import sdl2
from SDLCore.ui.widget import Widget

class BlinkSquare(Widget):
    """随时间闪烁的方块。"""
    def __init__(self, rect, color=(255, 255, 0, 255)):
        super().__init__(rect)
        self.color = list(color)
        self._t = 0.0

    def update(self, delta_time):
        self._t += delta_time
        self.visible = int(self._t * 2) % 2 == 0   # 每 0.5 秒闪一次

    def render(self, renderer):
        if not self.visible:
            return
        renderer.fill(self.abs_rect, tuple(self.color))

# 用法
from SDLCore.ui.panel import Panel
p = Panel((0, 0, 800, 600), color=(0, 0, 0, 0))
p.add_child(BlinkSquare((100, 100, 120, 60)))
  • renderer.fill(rect, color) 画实心矩形（RGBA）。
  • 绘制线：renderer.draw_rect(rect, color)；线段：renderer.draw_line([(x1,y1),(x2,y2)], color)。
  • 纹理：renderer.copy(sprite, dstrect=(x, y, w, h)) —— 必须显式传 dstrect，否则会拉伸到全屏。

5. 事件驱动的"按下即回调"模式

Button 的实现值得学习（内部状态机）：

MOUSEMOTION  → 更新悬停态（hover/normal）
MOUSEBUTTONDOWN(左键, 在内部) → state = PRESSED, 消费
MOUSEBUTTONUP(左键, 在内部)   → 触发 callback, state = NORMAL

自定义"文字菜单按钮"可参照此模式（见 mods/base_game/start_scene.py 的 _MenuButton）。
