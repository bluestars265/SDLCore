06 资源与图片

目标：学会加载图片（含 SVG）、使用缓存与异步加载。

1. ResourceManager —— 全局资源管理器

SDLCore/resource.py 的全局单例 resources 负责图片纹理的加载与缓存：

from SDLCore.resource import resources

resources.set_factory(factory)          # 应用启动时注册渲染工厂（一次即可）

同步加载（缓存命中直接返回）

sprite = resources.get("mods/base_game/resource/images/png/logo.png")
w, h = sprite.size                      # 获取原始尺寸

异步加载（后台线程解码，不阻塞主循环）

resources.load_async("resource/images/foo.png")
# ... 主循环中每帧调用：
resources.process_pending()             # 将解码完成的 surface 转为纹理
if resources.has("resource/images/foo.png"):
    tex = resources.get("resource/images/foo.png")
SDL 纹理必须在主线程创建，所以异步只做后台解码，转纹理统一在主线程。

状态查询

resources.has(path)        # 是否已缓存
resources.is_loading(path) # 是否正在后台解码
resources.failed(path)     # 是否已确认加载失败（不再重试）

2. 支持的图片格式（含 SVG）

经 SDL_image（IMG_Load）解码，支持：PNG / JPG / BMP / GIF / TGA / SVG。

  • SVG：SDL_image 2.8+ 内置矢量光栅化（pysdl2-dll 2.32.10 实测可用）。
  • 组件传 .svg 路径即可直接使用；渲染时拉伸到目标矩形。
# SVG 素材与 PNG 用法完全一致
Image((0, 0, 200, 60), path="mods/base_game/resource/images/svg/按钮框.svg")
ImageButton((0, 0, 200, 60), image_normal=".../按钮框.svg", factory=factory)

3. 使用图片的控件

控件图片入口
Imagepath / texture（保持宽高比居中）
ImageButtonimage_normal / image_hover / image_pressed
ProgressBarfill_image（填充纹理）、indicator_image（前端标记）
ScrollPanelthumb_image（滚动条滑块图片）

它们内部都经 resources.get() 获取纹理，同一路径只加载一次。

4. 加载界面如何预加载全部资源

main.py 启动时收集全部 mod 的 resource/images/ 图片，注入 loading 场景：

# 收集所有 mod 的图片路径
paths = []
for info in mod_manager.mods.values():
    img_dir = os.path.join(info.dir, "resource", "images")
    for root, _dirs, files in os.walk(img_dir):
        for f in files:
            if f.lower().endswith((".png", ".jpg", ".svg", ...)):
                paths.append(os.path.join(root, f))

# loading 场景每帧：
for p in paths:
    if not resources.has(p) and not resources.is_loading(p) and not resources.failed(p):
        resources.load_async(p)

5. 透明度与混合

  • 半透明颜色（A < 255）会被 BatchedRenderer 自动移出合批单独绘制，混合正确。
  • 图片控件渲染前会自动设置 SDL_BLENDMODE_BLEND，PNG 透明背景正确显示。
