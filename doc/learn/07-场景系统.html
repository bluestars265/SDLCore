07 场景系统

目标：用 Scene / SceneManager 组织多个界面（主菜单、游戏、结算…）并管理切换。

1. 为什么需要场景？

游戏通常有多个界面：加载界面、主菜单、关卡内、设置… 每个界面拥有独立的 UI 树。 Scene 封装"一棵 UI 树 + 生命周期钩子"，SceneManager 负责注册与切换。

2. 最小场景

from SDLCore.scene import Scene
from SDLCore.ui.button import Button
from SDLCore.ui.panel import Panel
from SDLCore.ui.label import Label

class MainMenuScene(Scene):
    """主菜单场景。"""
    def __init__(self, manager):
        super().__init__(manager)          # manager 为 SceneManager，self.ui 是 UIManager

    def on_enter(self):                    # 进入场景时调用
        self._build_ui()

    def _build_ui(self):
        self.ui.root_panel.color = (26, 28, 38, 255)
        p = Panel((0, 0, -1, -1), layout=VBoxLayout(spacing=16, padding=(80, 80, 80, 80)))
        title = Label((0, 0, -1, 40), text="主菜单", factory=self.game.factory)
        btn = Button((0, 0, -1, 50), text="开始游戏",
                     callback=lambda: self.manager.switch("game"))
        p.add_child(title)
        p.add_child(btn)
        self.ui.root_panel.add_child(p)

    def on_resize(self, width, height):    # 窗口尺寸变化钩子（可选）
        pass

3. 注册与切换

from SDLCore.scene import SceneManager

manager = SceneManager(game)                # game 提供 window / factory / renderer
manager.register("menu", MainMenuScene(manager))
manager.register("game", GameScene(manager))
manager.switch("menu")                      # 进入首场景
  • switch(name)：先调用当前场景的 on_exit()，再调用目标场景的 on_enter()。
  • 每帧由 SceneManager 转发：resize / handle_events / update / render 给当前场景。
  • manager.names() 返回全部场景名。

4. 生命周期钩子

钩子时机
on_enter()进入场景时（首次构建 UI 的惯用位置）
on_exit()离开场景时（基类已实现：停止 IME、清除焦点）
on_resize(w, h)窗口尺寸变化（基类已先 resize UI 树）
Scene 基类自动：resize() 时铺满根面板；render() 时渲染本场景 UI 树。

5. 场景间通信

SceneManager 提供两种机制：

# 1) shared_data：共享数据模型（字典，任意读写）
manager.shared_data["player_hp"] = 100

# 2) events：事件总线（发布/订阅，解耦）
from SDLCore.scene import EventBus
manager.events.on("player_died", handler)      # 订阅
manager.events.emit("player_died")             # 发布

在场景内便捷访问：

self.shared_data["score"] = 10                 # self.shared_data == manager.shared_data
self.events.emit("game.start")                 # self.events == manager.events

6. ModScene —— 配置驱动的场景

ModScene（SDLCore/scene.py）从 JSON 场景文件构建 UI，并自动添加底部场景切换栏：

from SDLCore.scene import ModScene

scene = ModScene(manager, "menu", "scenes/menu/scene.json",
                 bindings={"on_click": my_handler},
                 next_scene="game",
                 resource_resolver=resolver)
manager.register("menu", scene)
  • bindings：JSON 中声明的事件处理器名 → Python 回调。
  • next_scene：切换按钮指向的下一个场景（None 则不显示切换栏）。
