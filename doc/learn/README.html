SDLCore 学习教程

欢迎！本教程带你从零开始熟悉 SDLCore —— 基于 PySDL2 的通用 GUI 引擎 + MOD 化游戏框架。 学习完成后，你将能独立使用 SDLCore 组装界面、管理场景、编写自己的 MOD 与游戏逻辑。

前置知识

  • Python 3.13 基础语法（变量、函数、类、列表/字典）
  • 基本的面向对象概念（类、继承、方法）

学习路径

章节主题你将学会
01 环境准备与第一个窗口环境 / 最小程序安装依赖、创建窗口、主循环
02 核心概念与控件体系Widget / 坐标 / 控件树控件的本质、坐标系统、层级
03 布局系统Layout / 自适应用 VBox/HBox/Grid 自动排布控件
04 常用控件全部内置控件按钮/输入框/列表/进度条等用法
05 事件与交互事件分发 / 自定义控件交互逻辑、悬停、焦点、自定义
06 资源与图片ResourceManager / SVG图片加载、缓存、SVG 素材
07 场景系统Scene / SceneManager多界面组织、场景切换与通信
08 MOD 系统与项目组织MOD 机制主 mod、第三方 mod、依赖加载
09 配置驱动 UIUIBuilder / JSON用 JSON 声明界面、事件注入
10 实战示例综合实战组装一个完整游戏开始界面
11 常见问题FAQ常见坑与排查思路

阅读建议

  • 每章均含可直接运行的代码，建议边读边动手。
  • 需要查询 API 细节时，参考 doc/ 下的参考文档（widget.md、panel.md、layout.md 等）。
  • 结合项目源码阅读效果更佳：SDLCore/ 是引擎层，mods/base_game/ 是游戏主体。
  • 学完所有章节后，尝试在 mods/base_game/ 中新增自己的场景。

项目结构速览

II/
├── main.py                 # 启动入口：仅加载主 mod 与其他 mod 并驱动主循环
├── test_main.py            # 测试启动入口（额外加载 test_mods/）
├── SDLCore/                # 通用引擎层（GUI 控件、布局、场景、资源、MOD 系统）
│   └── ui/                 #   控件库（widget/panel/button/...）
├── mods/
│   ├── base_game/          # 主游戏 mod（游戏主体：loading/start 场景）
│   └── demo_mod/           # 第三方演示 mod
├── test_mods/test_game/    # 控件测试 mod（仅测试启动时加载）
├── resource/               # 根资源（字体等）
├── doc/                    # SDLCore 参考文档（本目录为教程）
└── game_doc/               # 游戏逻辑层文档
本教程位于 doc/learn/。开始吧 —— 第 1 章：环境准备与第一个窗口
